 4. YOUTUBE HESABINI BAĞLAMA — ADIM ADIM (sorunuz 3)
================================================================================

Ne gerekiyor: Google Cloud'da ücretsiz bir "OAuth istemcisi" oluşturup
agent'a bir kez YouTube hesabınıza erişim izni vermek. Yaklaşık 15 dakika.

A) Google Cloud tarafı (tarayıcıda, kendi Google hesabınızla)
   1. https://console.cloud.google.com/ → üstten "Proje seç" → "Yeni proje"
      → ad: ör. "video-hatti" → Oluştur.
   2. Menü → "APIs & Services" → "Library":
        • "YouTube Data API v3" → Enable
        • "YouTube Analytics API" → Enable  (analytics ve öğrenme döngüsü
          için gerekli; agent'ın kendi kurulum sihirbazı bunu söylemiyor)
   3. "APIs & Services" → "OAuth consent screen" (Google Auth Platform):
        • User type: External
        • Uygulama adı, destek e-postası, geliştirici e-postası: kendi
          bilgileriniz
        • "Test users" (Audience) bölümüne YouTube kanalının bağlı olduğu
          Google hesabını ekleyin
   4. "APIs & Services" → "Credentials" → "Create credentials" →
      "OAuth client ID" → Application type: "Desktop app" (Web DEĞİL)
      → Oluştur → "Download JSON" (client_secret_....json).
      Bu dosya gizlidir; sohbete yapıştırmayın.

B) Bağlantıyı yapma (kendi bilgisayarınızda önerilir)
   Onay ekranı tarayıcınızdan 127.0.0.1 adresine geri döndüğü ve Review
   Studio (yayın onay ekranı) http://localhost:3456 adresinde açıldığı için
   YouTube kısmı en rahat kendi bilgisayarınızda çalışır:
     git clone https://github.com/mk350174-cmd/Deneme.git
     cd Deneme
     git checkout claude/gallant-euler-vl6d3t   (ya da main'e birleştirildiyse main)
     npm run kur
     cd apps/youtube-agent
     npm run walkthrough
   → http://localhost:3456 açılır. Sihirbaz client_id / client_secret
     değerlerini ister (indirdiğiniz JSON'da), sonra Google giriş ekranını
     açar. Kanal hesabınızla girip izin verin. Bitince
     apps/youtube-agent/config/tokens.json oluşur (git'e girmez).
   → Kontrol: depo kökünde `npm run doctor` →
     "YouTube channel linked (OAuth) ✔"

   Alternatif (her şey bulutta kalsın isterseniz): Claude bu oturumda bir
   giriş bağlantısı üretir. İzin verdikten sonra tarayıcı "sayfa
   açılamadı" der; adres çubuğundaki http://127.0.0.1:…/?code=… adresini
   kopyalayıp gönderirsiniz, Claude bağlantıyı tamamlar. Kod tek kullanımlık
   ve kısa ömürlü. Ancak Review Studio'yu yine kendi bilgisayarınızda açmanız
   gerekir.

C) Bilmeniz gereken iki Google kısıtı
   • Uygulama "Testing" durumunda kaldıkça Google verdiği izni 7 günde bir
     sona erdirir. Haftada bir yeniden giriş gerekir. Kalıcı çözüm: OAuth
     consent screen → "Publish app" (In production).
   • Google'ın denetiminden (audit) geçmemiş API projelerinden yüklenen
     videolar YouTube'da "Özel" (private) olarak kilitlenir. İlk videolar
     için pratik yol: agent yükler, siz YouTube Studio'dan kontrol edip
     herkese açık yaparsınız (kilitliyse Studio'dan yeniden yükleyin).
     Kalıcı çözüm: Google'ın "YouTube API Services Audit" formu.

   Yayın modu tercihiniz:
     [ ] Agent yüklesin, özel kalsın, ben Studio'dan açayım
     [ ] Audit başvurusu yapacağım, sonra otomatik yayın
     [ ] Şimdilik yükleme yok; bitmiş MP4'ü ben elle yüklerim
